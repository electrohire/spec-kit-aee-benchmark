All arms share model, task inputs, seed/caps, tool interface and independent labels/graders. Register/freeze changes before inference; one approved local worker, no overlap/retry/resume. First protocol/infra/identity/context/output-limit/hardblock fault halts. Wrong classifications and valid nonpassing AEE outcomes are measured outcomes. Independent grades remain separate from AEE status, acceptance and token arithmetic. Publish uncertainty, unknown usage, public-case exposure and outcome-conditioned debugging honestly.
