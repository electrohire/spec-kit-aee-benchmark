# CLI contract
aee-bench preflight: machine, Docker, disk and credential-presence JSON.
aee-bench select: deterministic repository-stratified safe task manifest.
aee-bench freeze: immutable protocol/config/prompt hashes.
aee-bench dry-run: interleaved schedule without provider calls.
aee-bench run: all or named arm, isolated generation and append-only resume.
aee-bench grade: pinned upstream grader, explicit IDs and unique run ID.
aee-bench aggregate: usage/outcomes/grades, paired clustered uncertainty.
aee-bench article-table: tables with synthetic/not-run labels.
Errors return nonzero. JSON rejects NaN; undefined ratios are null with reasons.
Credentials are environment-only and never command arguments.
